પર્ચેઝ રજિસ્ટર ફોર્મેટઇનપુટ ટેક્સ ક્રેડિટની શરતો

પર્ચેઝ › ખરીદી પરત અને ડેબિટ નોટ

ખરીદી પરત: ડેબિટ નોટ, ક્રેડિટ નોટ અને જીએસટી

તમે સપ્લાયરને માલ પાછો મોકલો ત્યારે સામાન્ય રીતે બે નોટ બને છે: તમારી ડેબિટ નોટ જે માલ સાથે જાય, અને સપ્લાયરની ક્રેડિટ નોટ જે તેનું બિલ ઘટાડે. જીએસટીમાં સપ્લાયરની ક્રેડિટ નોટ જ ગણાય છે.

બે નોટ, એક પરત

  • તમારી ડેબિટ નોટ વેપારનો કાગળ છે. તે સપ્લાયરને કહે છે કે "અમે તમારું ખાતું ડેબિટ કર્યું છે", પરત કરેલા માલ કે ઓછા માલ કે ભાવના ફરક માટે, અને તેમાં આઇટમ, જથ્થો, ભાવ અને જીએસટી હોય છે. તેને માલ સાથે મોકલો.
  • સપ્લાયરની ક્રેડિટ નોટ જીએસટીનો કાગળ છે (CGST કાયદાની કલમ 34). સપ્લાયર તેને પોતાના મૂળ ટેક્સ ઇન્વોઇસ સામે બનાવે છે અને GSTR-1 માં બતાવે છે, જેથી તે વેચાણ પરનો તેનો ટેક્સ ઘટે છે.

જીએસટીમાં સપ્લાયરે બનાવેલી "ડેબિટ નોટ" કંઈક બીજી હોય છે: તે તેના ઇન્વોઇસની કિંમત વધારે છે. એટલે તમારી નોટ પર હંમેશા મૂળ બિલ નંબર લખો, અને તેની સામે સપ્લાયર પાસે ક્રેડિટ નોટ માગો.

એક ઉદાહરણ

બિલ SP/1182 (₹40,000 ના પાઇપ + 18% જીએસટી) માંથી ગુપ્તા હાર્ડવેર ₹5,000 ના પાઇપ પરત કરે છે કારણ કે તે ફાટેલા હતા.

ગુપ્તા હાર્ડવેર SP/1182 સામે ₹5,900 ની ખરીદી પરત લખે છે અને એટલાની ડેબિટ નોટ મોકલે છે. શર્મા પાઇપ્સ ₹5,900 ની ક્રેડિટ નોટ બનાવે છે. ગુપ્તાએ શર્મા પાઇપ્સને ₹5,900 ઓછા આપવાના, અને ગુપ્તાની ઇનપુટ ટેક્સ ક્રેડિટ ₹900 ઘટે છે.

જીએસટીની બાજુ

  1. ક્રેડિટ નોટની સમયમર્યાદા: સપ્લાયરે તેને મૂળ વેચાણના નાણાકીય વર્ષ પૂરું થયા પછીના 30 નવેમ્બર સુધી, કે પોતાના વાર્ષિક રિટર્નની તારીખ સુધી, જે પહેલું હોય, બતાવવી પડે (કલમ 34(2)).
  2. તમે તમારી ક્રેડિટ ઘટાડો છો: ક્રેડિટ નોટ તમારા GSTR-2B માં દેખાય છે, અને તેનો જીએસટી તમારી ઇનપુટ ટેક્સ ક્રેડિટમાંથી ઘટે છે.
  3. 1 ઑક્ટોબર 2025 થી સપ્લાયર ક્રેડિટ નોટ પર પોતાનો ટેક્સ ત્યારે જ ઘટાડી શકે જ્યારે ખરીદનારે તેની ઇનપુટ ટેક્સ ક્રેડિટ પાછી કરી હોય (કલમ 34(2) ની જોગવાઈ, ફાઇનાન્સ એક્ટ 2025). એટલે હિસાબ પતાવતા પહેલાં સપ્લાયર તમને પોર્ટલ પર ક્રેડિટ નોટ એક્સેપ્ટ કરવા કહી શકે.

અહીં કેવી રીતે લખવું

ખરીદી પરત ખોલો: સપ્લાયર પસંદ કરો, "કયા બિલ નં.ની પરત" માં મૂળ બિલ નંબર લખો, આઇટમ અને જીએસટી બરાબર મૂળ બિલ જેવા ભરો, અને સેવ કરો. પરત પર્ચેઝ રજિસ્ટરમાં માઇનસ લાઇનમાં દેખાય છે, સપ્લાયરનું બાકી ઘટાડે છે, અને તે લાઇનનું ડેબિટ નોટ બટન તમારા વેપારની વિગત, સપ્લાયરનો GSTIN અને મૂળ બિલ નંબર સાથે નોટ અંગ્રેજીમાં પ્રિન્ટ કરે છે.
